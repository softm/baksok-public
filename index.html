서해박속낙지

광명에 위치한 낙지요리 전문점입니다. 기존 홈페이지 자료에는 국산 낙지와 충남 서산 농장에서 직접 재배한 박으로 박속낙지탕(연포탕)을 조리하고, 낙지먹물 볶음밥·칼국수·어리굴젓비빔밥을 함께 제공한다고 기록되어 있습니다.

기존 공개 사이트의 소개·메뉴·위치 정보를 해당 공개 GitHub 저장소에 보존합니다.
